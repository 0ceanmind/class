# 🧱 Class Wall

Add your name card and appear on the live class website!

## Steps
1. Click **Fork** → **Create fork**
2. In your copy, open the folder `contributors`
3. Click **Add file** → **Create new file**. Name it `your-username.md` (your exact GitHub username)
4. Type ONE line about you (see `contributors/_template.md`)
5. Click **Commit changes**
6. Go back to the class repo → **Pull requests** → **New pull request** → **Create pull request**

When your lecturer merges it, your card appears on the Class Wall. 🎉

## Rules
- File name = your GitHub username + `.md`
- One line only. Keep it friendly.
"# class"
